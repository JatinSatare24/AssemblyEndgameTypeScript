# 🧩 Assembly Endgame (TypeScript)

An interactive word-guessing game inspired by low-level programming concepts, built using React and TypeScript. This project focuses on state management, conditional rendering, and type-safe development.

---

## 🚀 Overview

Assembly Endgame is a game where the user guesses letters to complete a hidden word. Each incorrect guess progressively affects the game state, creating a dynamic and engaging experience.

The project demonstrates how to manage complex UI states and logic using React with TypeScript.

---

## 🛠️ Tech Stack

* React
* TypeScript
* JavaScript
* CSS

---

## 🎮 Game Logic

* A random word is selected
* User guesses letters
* Correct guesses reveal positions
* Incorrect guesses affect game progression
* Game ends on win or loss condition

---

## ✨ Features

* 🔤 Dynamic word rendering
* ⌨️ Interactive letter selection
* ❌ Incorrect guess tracking
* 🏆 Win/Loss detection
* 🔄 Game reset functionality
* 🔒 Strong typing using TypeScript
